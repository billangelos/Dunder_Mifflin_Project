# 19. Status Definitions

## Planned

The artifact has been identified as part of the security program but has not yet been completed and approved.

## Draft

The artifact is under development and has not received final approval.

## Approved

The artifact has completed its initial development and approval process.

Approved status does not by itself establish that every control, procedure, or requirement described by the artifact has been implemented or validated.

## Active

The artifact is a living operational or reference record that is maintained as program information changes.

## Retired

The artifact is no longer active but is retained when required for historical or evidentiary purposes.

---

# 20. Repository Maintenance

This index must be updated when:

- A new controlled artifact is added.
- An artifact identifier changes.
- An artifact title changes.
- An artifact status changes.
- An artifact is retired.
- Repository structure materially changes.

Artifact status describes the status of the document itself.

An Approved artifact may contain requirements, treatments, controls, procedures, or capabilities that remain planned, partially implemented, implemented but unvalidated, or otherwise not fully effective.

Approved document status must not be interpreted as evidence that every control described by the artifact has been implemented.

Only actual implemented and appropriately validated controls may receive credit when evaluating current control effectiveness or residual risk.
